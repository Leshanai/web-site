# web-site

## Hello World

This repository contains the source files for the project's web site.

## Files
- `index.html`: Home page for Serene Leaf Tea House (featuring hero section, featured teas, about story, and contact/hours info with interactive buttons and Sign Up navigation).
- `signup.html`: Sign Up page featuring a registration form with Full Name, Email, Password, and Confirm Password fields, client-side validation, loading states, success feedback, and navigation links.
- `style.css`: Clean, responsive stylesheet defining typography, colors, and layout for the site (including dark mode compatibility and button hover effects).
