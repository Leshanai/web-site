# web-site

## Hello World

This repository contains the source files for the project's web site.

## Files
- `index.html`: Home page for Serene Leaf Tea House (featuring hero section, featured teas, about story, and contact/hours info with interactive buttons).
- `style.css`: Clean, responsive stylesheet defining typography, colors, and layout for the home page (including `.btn` and `.btn-secondary` hover effects).
